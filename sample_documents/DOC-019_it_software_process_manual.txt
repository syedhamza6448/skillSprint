IT & SOFTWARE PROCESS MANUAL
Document ID: DOC-019
Version: 1.0
Effective Date: 2023-06-01

=============================================================
SECTION 1: IT SUPPORT PROCESS
=============================================================

1.1 Internal IT support requests are submitted via the IT helpdesk portal (helpdesk.nexacore.internal).
1.2 All hardware issues must be reported to IT within 1 business day.
1.3 IT support SLA for internal requests:
    - Software/access issues: resolved within 4 business hours
    - Hardware replacements: within 2 business days
    - Network outages: immediate escalation; resolution target 2 hours

1.4 Software installation requests require IT approval. Unapproved software is not permitted on company devices.

=============================================================
SECTION 2: SOFTWARE DEVELOPMENT LIFECYCLE (SDL)
=============================================================

2.1 All platform updates to NexaCRM Pro follow a monthly release cycle.
2.2 Hotfixes for P1 production issues are released within 24-48 hours of root cause identification.
2.3 All code changes must pass peer code review before merging.
2.4 Automated test coverage must be maintained above 80% for core modules.
2.5 Security scanning is run on every release candidate using approved SAST tools.

=============================================================
SECTION 3: DATA BACKUP & RECOVERY
=============================================================

3.1 Client databases are backed up daily (full backup) and every 4 hours (incremental).
3.2 Backup retention: 30 days for daily backups, 1 year for monthly backups.
3.3 Recovery Point Objective (RPO): 4 hours for client data.
3.4 Recovery Time Objective (RTO): 2 hours for critical systems.
3.5 Disaster recovery drills are conducted twice per year.

=============================================================
SECTION 4: ACCESS MANAGEMENT
=============================================================

4.1 System access is provisioned within 1 business day of HR confirmation of a new employee.
4.2 Access is immediately revoked upon HR notification of employee termination.
4.3 Privileged access (admin/superuser) requires quarterly review and re-approval.
4.4 Access to Production environments requires dual authorization (engineer + team lead).

NOTE [CONFLICT-011]: The Information Security Policy (DOC-006) states access to client data is granted on a need-to-know basis. The IT Process Manual (DOC-019) specifies that Production environment access requires dual authorization. Both requirements apply cumulatively for Software Support Engineers.

=============================================================
SECTION 5: CHANGE MANAGEMENT
=============================================================

5.1 All changes to production systems must follow the Change Advisory Board (CAB) process.
5.2 Emergency changes (required to resolve a P1 incident) may bypass CAB but must be retrospectively approved within 24 hours.
5.3 Change requests must include: description, risk assessment, rollback plan, and test evidence.
