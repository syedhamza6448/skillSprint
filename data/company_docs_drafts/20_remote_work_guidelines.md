# NimbusWorks Remote Work Equipment Guidelines
Version: 1.0 | Effective: 2026-01-01

## 1. Remote Workspace Standards
### 1.1 Ergonomic Workspace
Remote employees are expected to maintain a clean, quiet, and ergonomically safe home office environment suitable for professional work.

### 1.2 Home Internet Requirements
Employees working remotely must maintain a reliable broadband internet connection with a minimum download speed of 50 Mbps and upload speed of 10 Mbps.

## 2. Equipment Allowance and Peripherals
### 2.1 Work-From-Home Stipend
Full-time remote employees are eligible for a one-time work-from-home setup stipend of $500 to purchase ergonomic desks or chairs.

### 2.2 IT Peripherals Provisioning
DevOps/IT Engineers provide remote employees with standard IT peripherals including headsets, webcams, and USB hubs upon request.

## 3. Security in Remote Environments
### 3.1 Device Physical Security
Remote laptops must never be left unattended in public spaces. Screen locks must be set to activate automatically after 5 minutes of inactivity.

### 3.2 Home Network Security
Remote workers must secure home Wi-Fi networks with WPA3 encryption and change default router passwords prior to connecting company devices.

## 4. Offboarding Remote Assets
### 4.1 Return Shipping Protocols
Upon departure, remote employees will receive pre-paid shipping labels from Operations Coordinators to return all company equipment within 5 business days.
